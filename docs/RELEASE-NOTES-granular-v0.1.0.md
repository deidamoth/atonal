# Vocoder + Granular FX — experimental v0.1.0

Separate expansion of the owner-confirmed WORKING VOCODER v1.0.0. The baseline repository remains unchanged.

- Button 2 toggles FX; Knob 2 adds the granular layer. Base vocoder wet level is now fixed at its previous maximum (0.55). Knob 1 and Button 1 retain their functions.
- Four randomized grain heads, stereo movement, subtle octave layers and a damped delay tail.
- Exact baseline passthrough with FX bypassed, compared at the same wet setting; 30 ms fades and bounded output.
- Firmware build and host tests passed. **Not flashed or hardware-tested yet.** No DFU device was found.
- Includes a synthetic audio preview: bypass / half FX / full FX in three five-second sections.
